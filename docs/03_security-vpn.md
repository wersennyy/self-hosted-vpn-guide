## 🛡️ Безопасность сервера (Защита от атак и брутфорса)

Как только ваш VPS активируется, хакерские боты начинают круглосуточно сканировать его порты и пытаться подобрать пароль к SSH. Чтобы ваш VPN-сервер не взломали и не заблокировали за спам, обязательно выполните эти 3 шага по защите системы.

> [!IMPORTANT]
> Выполняйте шаги строго по порядку. Не закрывайте текущую сессию терминала, пока полностью не убедитесь, что всё настроено верно, иначе вы можете заблокировать доступ к собственному серверу!

---

### Шаг 1. Перенос SSH на нестандартный порт
Боты в 99% случаев брутфорсят именно стандартный `порт 22`. Если изменить его, например, на `2222`, поток автоматических атак снизится до нуля.

1. Откройте конфигурационный файл SSH:
   ```bash
   sudo nano /etc/ssh/sshd_config
   ```
2. Найдите строку `#Port 22` (или `Port 22`).
3. Раскомментируйте её (уберите знак `#`, если он есть) и измените номер порта:
   ```text
   Port 2222
   ```
4. Сохраните файл (`Ctrl+O`, затем `Enter`) и выйдете (`Ctrl+X`).
5. **Если вы используете брандмауэр UFW, обязательно разрешите новый порт перед перезапуском!**
   ```bash
   sudo ufw allow 2222/tcp
   ```
6. Перезапустите службу SSH, чтобы применить настройки:
   ```bash
   sudo systemctl restart ssh
   ```
*Теперь при новом подключении к серверу вам нужно будет указывать порт 2222 (в Termius или через команду `ssh root@IP -p 2222`).*

---

### Шаг 2. Вход по SSH-ключам (Отключение паролей)
Подбор текстового пароля — это вопрос времени. Авторизация по SSH-ключам использует асимметричное шифрование: войти на сервер сможет только тот компьютер, на котором физически лежит ваш приватный ключ. При этом вход по обычным паролям полностью блокируется.

1. **На своем домашнем компьютере** (в терминале Linux/Mac или PowerShell в Windows) сгенерируйте пару ключей:
   ```bash
   ssh-keygen -t ed25519 -C "my-vps-key"
   ```
   *(Нажимайте Enter, чтобы сохранить настройки по умолчанию)*.
2. Скопируйте ваш публичный ключ на VPS-сервер:
   ```bash
   ssh-copy-id -p 2222 root@IP_ВАШЕГО_СЕРВЕРА
   ```
3. Проверьте, что теперь вы можете зайти на сервер без ввода пароля.
4. **Полностью отключите вход по паролям.** На сервере снова откройте файл `/etc/ssh/sshd_config`, найдите и измените следующие параметры:
   ```text
   PasswordAuthentication no
   PermitRootLogin prohibit-password
   ```
5. Перезапустите SSH: `sudo systemctl restart ssh`. Теперь боты физически не смогут перебирать пароли.

### Шаг 3. Установка Fail2Ban (Автобан для хакеров)
**Fail2Ban** — это умный защитник. Он сканирует системные логи и, если видит, что кто-то несколько раз подряд неправильно ввел пароль или пытается взломать вашу панель `3x-ui`, он автоматически блокирует IP-адрес этого атакующего на уровне системы (через встроенный брандмауэр).

1. Установите утилиту одной командой:
   ```bash
   sudo apt update && sudo apt install fail2ban -y
   ```
2. Запустите и включите автозапуск при старте сервера:
   ```bash
   sudo systemctl start fail2ban
   sudo systemctl enable fail2ban
   ```
3. Базовые настройки уже защищают SSH. Чтобы проверить статус работы и список забаненных ботов, используйте команду:
   ```bash
   sudo fail2ban-client status sshd
   ```
