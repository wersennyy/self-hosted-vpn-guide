# 📞 Обход белых списков через звонки (медленный, но надежный способ)

## ⚠️ Сразу предупреждаю
Этот способ — **экстренный**, не для повседневки. Скорость будет низкой, пинг высоким. Но когда всё остальное заблокировано — это один из немногих рабочих вариантов. Зайти в соц сеть - хватит.
## 🔍 БС - это что?
Когда оператор включает **белые списки**, всё блокируется по умолчанию. Разрешены только сайты из утверждённого перечня:
- Госуслуги, банки
- Яндекс, VK, Mail.ru
- Соцсети и поисковики из реестра Минцифры

Обычные VPN (WireGuard, OpenVPN) не работают — их IP нет в белом списке, подключение обрывается.

### 💡 Как это работает
Идея в том, чтобы пустить трафик через сервисы, которые **уже в белом списке** — видеозвонки:
- **Yandex Telemost**
- **VK Calls** (через TURN-серверы VK)
- **WB Stream**

Трафик маскируется внутри видеозвонка. Для DPI-систем оператора это выглядит как обычный VoIP-трафик, а не VPN-туннель.

---

## 🛠️ whitelist-bypass (kulikov0)
### Что это
Open-source инструмент, который создаёт SOCKS5-прокси через видеозвонок. Трафик идёт через медиа-релеи VK/Yandex, поэтому обходит белые списки.

### Реальные цифры

| Параметр | Значение |
|----------|----------|
| Скорость | 50-500 Kbps |
| Пинг | 300-800ms |
| Время жизни | 1-3 часа |
| Для чего | Текст, почта, мессенджеры |
| Не для | YouTube, торренты, стриминг |

## 📱 Настройка на Android

### Вариант 1: whitelist-bypass.apk

**Шаг 1. Скачать APK**
- Идём на GitHub: https://github.com/kulikov0/whitelist-bypass/releases
- Качаем файл `whitelist-bypass-vX.X.X.apk` (последняя версия)

**Шаг 2. Установить**
1. Разрешить установку из неизвестных источников:
   - Настройки → Безопасность → Неизвестные источники → ВКЛ
   - Или: Настройки → Приложения → Браузер → Установка неизвестных приложений → Разрешить
2. Открыть скачанный APK → Установить

**Шаг 3. Запустить приложение**
1. Открыть whitelist-bypass
2. Вставить ссылку на видеозвонок (Telemost/VK)
3. Нажать **GO**

**Шаг 4. Настроить прокси в системе**

**Android 10+**:
1. Настройки → Wi-Fi
2. Долгое нажатие на свою сеть → Modify Network
3. Advanced → Proxy: Manual
4. Host: `127.0.0.1`, Port: `1080`
5. Сохранить

**Android 9 и ниже**:
1. Настройки → Wi-Fi
2. Долгое нажатие на сеть → Изменить сеть
3. Показать дополнительные настройки → Прокси-сервер: Вручную
4. Имя хоста: `127.0.0.1`, Порт: `1080`

**Шаг 5. Проверить**
- Открыть браузер
- Зайти на https://2ip.ru или https://whoer.net
- Если показывает IP сервера — всё работает!

## 💻 Настройка на Windows

### Desktop-версия whitelist-bypass

**Шаг 1. Скачать**
- GitHub Releases: https://github.com/kulikov0/whitelist-bypass/releases
- Скачать `whitelist-bypass-win-x64.exe` (или .msi)

**Шаг 2. Установить**
1. Запустить установщик
2. Принять лицензию
3. Выбрать папку установки (можно по умолчанию)
4. Установить

**Шаг 3. Запустить**
- Открыть whitelist-bypass из меню Пуск или с рабочего стола

**Шаг 4. Настроить**
1. Вставить ссылку на звонок (Telemost/VK/WB Stream)
2. Нажать **Connect**

**Шаг 5. Настроить прокси в системе**

**Windows 10/11**:
1. Параметры → Сеть и Интернет → Прокси-сервер
2. Включить «Использовать прокси-сервер»
3. Адрес: `127.0.0.1`, Порт: `1080`
4. Сохранить

**Шаг 6. Проверить**
- Открыть браузер → https://2ip.ru
- Если IP сменился — работает!

## 🐧 Настройка на Linux

### Desktop-версия (Electron)

**Шаг 1. Скачать**
1. Открой сайт: **https://github.com/kulikov0/whitelist-bypass/releases**
2. Найди последний релиз (v0.3.8 или новее)
3. В разделе **Assets** скачай файл для Linux:
   - `.deb` (для Ubuntu/Debian)
---
**Шаг 2. Установить**
Дважды кликни по файлу → установится автоматически.
---
**Шаг 3. Запустить**
  1. Открой меню приложений
  2. Найди **WhitelistBypass**
  3. Запусти
---
**Шаг 4. Настроить прокси в системе**
**GNOME (Ubuntu, Fedora)**:
1. Открой **Settings** → **Network** → **Network Proxy**
2. Method: **Manual**
3. HTTP/HTTPS/SOCKS Host: `127.0.0.1`, Port: `1080`
4. Нажми **Apply**

**KDE Plasma**:
1. Открой **System Settings** → **Network** → **Proxy**
2. Выбери **Manual Proxy Configuration**
3. SOCKS Host: `127.0.0.1`, Port: `1080`
4. Нажми **Apply**
---
**Шаг 5. Проверить**
```bash
curl ifconfig.me
```
- Если показывает IP сервера — всё работает!

## 📞 Где взять ссылку на звонок

### Яндекс.Телемост
1. Зайти на https://telemost.yandex.ru
2. Создать новый звонок
3. Скопировать ссылку
4. Отправить себе в Telegram/почту

### VK Calls
1. Открыть VK → Звонки → Создать групповой звонок
2. Скопировать ссылку
3. Использовать в whitelist-bypass

---

## 🔄 Как продлить жизнь соединению

1. **Менять звонки**: когда соединение падает — создать новый звонок, обновить ссылку
2. **Использовать IPv6**: если хостинг выдаёт IPv6, включить в настройках (некоторые операторы ещё не блочат)
3. **Комбинировать**: если Telemost блочат — попробовать VK Calls или WB Stream

---

## 🧪 Проверка работы

1. **Отключить Wi-Fi**, оставить только мобильную сеть
2. **Открыть** сайт, который не работает без VPN (YouTube, Discord)
3. **Запустить** speedtest (ожидай 50-500 Kbps)
4. **Проверить** утечки DNS: https://dnsleaktest.com

## ❓ Частые проблемы

### «Не могу подключиться к звонку»
- Проверь ссылку (должна быть полной, с `https://`)
- Попробуй другой сервис (VK вместо Telemost)
- Пересоздай звонок

### «Прокси не работает»
- Проверь, что whitelist-bypass запущен
- Перезапусти приложение
- Проверь, что порт `1080` не занят другим приложением

### «Скорость очень низкая»
- Это нормально для VoIP-туннелей (50-500 Kbps)
- Попробуй другой звонок/сервис

### «Соединение обрывается через 30 минут»
- Это ограничение самих сервисов звонков
- Пересоздай звонок, обнови ссылку
- Используй IPv6 (если доступно)
