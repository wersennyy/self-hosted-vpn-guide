## О проекте

Мне 15, и я изучаю сети, Linux и кибербезопасность.

Этот репозиторий — мой путь к собственному VPN-серверу: VPS, Xray Core, `VLESS + Reality`, защита сервера и реальные ошибки, которые пришлось решить по дороге.

Здесь я также разбираюсь с `DPI`, блокировками и белыми списками — и проверяю, какие решения работают.
